## 🚀 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Udaykasera/React_Core_Mastery.git
    ```

2.  **Navigate to a specific module:**
    ```bash
    cd Hooks  # or any other subfolder
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```
